Crosshair Migrator

Converts pre–Rush Hour CS2 crosshairs to the new cl_crosshair_length / _gap / _thickness settings.

    SettingOldNew
    
    
  
    

  
    The small squares show each crosshair at actual size. Old crosshair size and thickness were measured in 1/480ths of screen height, and the gap was 4 + gap in raw pixels. New values are plain pixels at the resolution you set them at (Valve's 24 Sep notes), so the tool gives you the exact pixels you had. Enter the command while the game is running at your normal resolution. If you switch resolution later, CS2 rescales the values for you. The old formula comes from CS:GO's source code and matches CS2 screenshots.
